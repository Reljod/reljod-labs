# Prism (single-forward-pass Decision Models): agent notes

Read this before you change `src/features/prism/`, `/demos/prism`, `/api/prism/*` or `e2e/prism.spec.ts`. The rules for every demo are in the root `AGENTS.md`.

- A live demo at `/demos/prism` in four places (Prism, Tribunal, Cascade, Lab): showcases November 2026 non-generative Decision Models (`experimental_decide` via Vercel AI Gateway: `microsoft/decision-1.1`, `liquid/d1.2-ultra`, `perplexity/pplx-decider-v1.3`, `nace-ai/drex-max-finance`, `google/gemini-decision-1`, `baseten/joey-1`) returning calibrated probabilities in one forward pass with zero output tokens. Domain language: `src/features/prism/GLOSSARY.md`.
- Pure decision physics (`domain/routing.ts`): `shannonEntropy`, `compositeRisk`, `routeChute`, and `tribunalConsensus` run deterministically in code, so threshold sliders re-route Slips and Cascade bins at 60fps with zero extra model calls.
- Three gated routes under `/api/prism/` (`refract`, `tribunal`, `cascade`, all matched in `src/proxy.ts` and guarded with `requireOwner()`). Hourly call caps live in `LIMITS` (`domain/limits.ts`) and are taken in Postgres under a transaction-scoped advisory lock (`server/rate.ts`, `prism.rate_hits`, counting actual model calls per request: 1 for refract, juror count for tribunal, item count for cascade) before the first model call or stream starts, together with a global daily cap on every kind's calls (`LIMITS.callsPerDay`, decided by the pure `rateVerdict`); skipped for trusted `e2e` visitors.
- Env: `PRISM_DATABASE_URL` (falls back to `CLIENT_MANAGER_DATABASE_URL`), optional `PRISM_AI_GATEWAY_API_KEY` (falls back to `DOCUMENT_COMPLIANCE_AI_GATEWAY_API_KEY`); requires `RATE_LIMIT_SALT` and shares `E2E_BYPASS_TOKEN`. Migration: `supabase/migrations/20261120120000_prism.sql` (added with `git add -f`; apply before deploying). `prism.rate_hits` is registered in `access.owned_tables`.
- Tests: `e2e/prism.spec.ts` is skipped unless `E2E_PRISM=1` and runs stubbed (`x-prism-stub` carrying the e2e bypass token, zero model spend). Run it only when asked.
